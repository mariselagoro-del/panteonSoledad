## 📂 Organización de Carpetas
- `src/components/common/`: Componentes comunes y reutilizables (`Navbar`, `StatsCards`, `ContextMenu`).
- `src/components/modals/`: Modales (`ModalRegistroFosa`, `ModalEditarFosa`).
- `src/pages/`: Vistas (`ControlEspacios`, `PlanoGeneral`, `ReportesIngresos`, `Dashboard`).
- `src/constants/`: Constantes y datos iniciales (`panteonData.js`).
- `src/services/`: Capa HTTP hacia backend (`panteonService.js`).
- `src/styles/`: Constantes de estilo JS (`panteonStyles.js`).
